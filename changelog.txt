*** Matrix BOGO WooCommerce Promotion Changelog ***

2026-05-12 - version 1.0.9
* Fixed: wpdb::prepare() called without a placeholder in RulesRepository::get_active_rules() — caused non-fatal notice on every page load
* Fixed: Unescaped output in PromotionsList.php — trigger product names and category names now wrapped in esc_html() at echo point
* Fixed: Unsanitized $_POST['prune_days'] and $_GET['paged'] in Logs.php — replaced with absint( wp_unslash() )
* Fixed: Potential file inclusion vulnerability in Autoloader.php — added path-traversal guard rejecting class names containing '..'
* Updated: WC tested up to 10.0 (was 9.6)
* Updated: Tested up to WordPress 6.9 (was 6.7)

2026-05-12 - version 1.0.8
* Fixed: Fatal TypeError on every page load — removed strict WC_Product type hint from gift_is_purchasable() (WooCommerce passes string in some contexts)
* Fixed: White screen on activation caused by malformed wp_enqueue_script() calls in Assets.php
* Fixed: Action Scheduler notices — deferred as_next_scheduled_action/as_schedule_recurring_action until after data store is initialized
* Fixed: ProgressBar::init() now checks progress_bar_enabled setting before running
* Fixed: Added show_notices to Installer default settings

2026-05-12 - version 1.0.7
* Improved: Promotions list dashboard now shows expandable detail rows per promotion
* Added: Each row can be expanded to reveal Promotion Settings (trigger products/categories, thresholds)
* Added: Conditions summary — all condition groups (AND within group, OR between groups) displayed inline
* Added: Rewards summary — reward type, product name, quantity, discount value shown per reward
* Added: Human-readable type labels in the list ("Buy X Get Y", "Category Get Gift", etc.)
* Added: Description excerpt shown below promotion name in the list

2026-05-11 - version 1.0.6
* Fixed: Promotions were evaluated but gifts/discounts never appeared in cart
* Fixed: All 5 promotion types now correctly read flat rule_data keys saved by the builder
* Fixed: Rewards from the matrix_bogo_rewards table are now loaded and injected into each promotion type at evaluation time
* Fixed: cart_quantity_get_gift type key mismatch (was cart_qty_get_gift in registry)
* Fixed: Fixed/percent-discount rewards now apply without requiring a product_id
* Added: cheapest_free reward type now supported
* Added: Percentage discount applies to full cart subtotal when no product_id is set

2026-05-11 - version 1.0.5
* Fixed: "Failed to save promotion" — description column was missing from the database schema
* Added: description column to matrix_bogo_rules table (DB version 1.0.1)
* Added: Automatic DB schema upgrade on plugins_loaded — no deactivate/reactivate needed

2025-05-11 - version 1.0.0
* Initial release
* 5 promotion types: Buy X Get Y, Buy X Get X, Spend Amount Get Gift, Cart Quantity Get Gift, Category Get Gift
* 16 condition types across customer, cart, order history, and time groups
* Priority manager with stackable and exclusive promotion support
* Auto-apply gifts and customer-choice gift popup
* Action Scheduler integration for scheduled promotion activation/expiration
* Analytics dashboard with daily redemption chart and revenue attribution
* Full REST API at matrix-bogo/v1 (CRUD for promotions, analytics, logs)
* Import/export promotions as JSON
* HPOS (High-Performance Order Storage) compatibility declared
* Multilingual-ready with complete POT file
* Log viewer with level filtering and retention management
